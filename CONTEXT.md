# Hoai Le Thi Portfolio

A personal portfolio site (Qwik + Qwik City) presenting Hoai Le Thi's work, sourced from a Builder.io CMS.

## Language

**Project**:
A single portfolio work item pulled from the CMS and shown in the project list.
_Avoid_: Item, entry, piece

**Project Category**:
The Art/Design classification a Project belongs to, represented in code as the `'art' | 'design'` union.
_Avoid_: type, kind
